## Jameel Noori Nastaliq (جمیل نوری نستعلیق)

This repository contains the **Jameel Noori Nastaliq** font, a classic and highly-regarded typeface for the Urdu language. It is released under the permissive MIT License, making it suitable for both personal and commercial projects.

## About the Font

Jameel Noori Nastaliq is a beautiful calligraphic font that faithfully represents the Nastaliq script style, which is the predominant writing style for Urdu in South Asia. It is ideal for:

*   Urdu publishing and print design
*   Web development for Urdu language websites
*   Desktop publishing
*   Any digital project requiring authentic, high-quality Urdu typography

## Features

*   **Authentic Nastaliq Style:** True to the traditional calligraphic form.
*   **Multiple Formats:** Available in common formats (e.g., ttf, WOFF2 for the web).
